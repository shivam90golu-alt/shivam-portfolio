# Shivam Kumar - Data Analyst Portfolio

This is a GitHub Pages ready portfolio website.

## How to publish on GitHub Pages

1. Extract this ZIP file.
2. Open your GitHub repository.
3. Click **Add file > Upload files**.
4. Upload all extracted files and folders: `index.html`, `style.css`, `script.js`, `assets`, and `README.md`.
5. Click **Commit changes**.
6. Go to **Settings > Pages**.
7. Select **Deploy from a branch**.
8. Branch: `main`, Folder: `/ (root)`.
9. Click **Save**.
10. Wait 2-5 minutes and open your GitHub Pages link.

## Important

Do not upload the ZIP file directly. Upload the files inside the extracted folder.
